# 1.3.1 上机验证清单

请先在托盘退出旧版，再覆盖整个程序目录，保留 hxdou-data。启动后确认面板日志右侧显示 v1.3.1；未连接客户端时，状态栏只显示“等待游戏客户端…”，不展示重试次数。

## 实时海克斯与选人侧窗

- [ ] 进入海克斯选人界面并获得英雄，客户端旁自动出现侧窗，不抢焦点；先显示查询中，随后显示当前英雄。
- [ ] 侧窗显示来源 ARAMKit、最新版本、数据发布日期与本次获取时间；数据日期可能早于当前时间，表示源站最新发布批次。
- [ ] 换英雄立即清空旧卡片，重新查询；连续快速换人，最终只能显示当前英雄。下一局相同英雄也重新获取。
- [ ] 推荐显示胜率、样本数、品质、出现轮次，可展开强化效果；切换轮次/品质和样本门槛时结果对应变化。
- [ ] 切换“高胜率组合”显示真实组合与样本；轮次、品质筛选禁用，样本门槛仍有效。源站未发布或样本不足时应显示无数据说明。
- [ ] 切换全段位/高分段会重新联网；点“重新获取”时获取时间更新。
- [ ] 断网后换英雄或重新获取，应显示获取失败，不残留旧英雄数据；网络恢复后可重试。
- [ ] 移动客户端时侧窗跟随；右侧空间不足改贴左侧，两边不足保持在屏幕工作区内。
- [ ] 客户端最小化、切到其他程序或离开选人时自动隐藏；返回选人前台恢复。
- [ ] 关闭侧窗后当前英雄不再弹出；换英雄或通过主面板“打开英雄海克斯侧窗”可再打开；关闭自动吸附开关后不自动显示。
- [ ] 多屏和不同缩放下位置正常；主面板折叠区也能显示推荐。失败时导出诊断，查看 status.hex.status/details/endpoint/version/dataDate/fetchedAt。

本地已完成 21 项自检、两个英雄的真实联网查询、13 项 WebView2 界面检查；以上真实客户端交互仍需上机验证。

## 自动接受

- [ ] 开启自动接受，延迟设为 800～1500ms，排海克斯大乱斗；待接受后应自动进入选人。
- [ ] 如有人拒绝或超时导致重新匹配，下一次待接受仍能自动接。
- [ ] 连续两局、启动后等待几分钟再排队都能生效。
- [ ] 延迟期间关闭开关或手动接受，不应再发额外请求。
- [ ] 若失败，在待接受时点调试页「待接受状态」，再「导出诊断」，检查 status.autoAccept 的 state/playerResponse/queueId/lastError/updatedAt。

## 装备价值浮层

- [ ] 使用无边框窗口模式，按住 Tab 出现，松开隐藏。
- [ ] 浮层位于屏幕上方居中（工作区顶部向下 80px），查看海克斯详情时不遮挡下方内容。
- [ ] 开局空装备可为 0；购买装备后再按 Tab，双方装备价值应增加。
- [ ] 持续按住 Tab 时买卖装备，约一秒刷新，不能一直停在初始 0。
- [ ] 自己在红方时，差值仍为“自己方减对方”；这里比较装备价值，不含手头金币。
- [ ] 若显示 -- 或购买后仍全为 0，在游戏内点「对局内数据（2999）」并「导出诊断」。新诊断含 livePlayers 原始装备价格、liveError 和 status.gold。

## 队友与聊天

- [ ] 选人阶段显示四位队友；换英雄不重复请求战绩。
- [ ] 开启自动播报后，每位队友单独一条，通常共四条，格式如：哈哈哈#123 中等马 kda 3.1 最近胜率 46%。
- [ ] 没有楼号、评级括号和旧前缀；换英雄不再自动发送一次。
- [ ] 无战绩时显示 --，不编造胜率或评级。
- [ ] 如失败，诊断查看 status.chat 的 sentCount/totalCount/messages/attempts；部分失败会保留已发数量。

## 旧出装与启动

- [ ] 面板、托盘及调试页没有推荐出装写入入口。
- [ ] 升级后可点一次「清理旧出装」，仅删除本工具的 !!!hxdou-*.json。
- [ ] 最小化收进托盘；再次双击 exe 能唤回面板。
