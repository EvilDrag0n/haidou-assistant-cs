# 1.3.0 · 实时英雄海克斯与选人侧窗（2026-10-30）

选定或更换英雄后，助手从 ARAMKit 获取最新版本索引、该英雄的海克斯统计和中文资源，展示推荐与真实组合胜率。每次换人、切换统计段位或点击重新获取均重新联网；不保存推荐缓存，不回退到静态推荐或旧英雄数据。相同英雄的 500ms 轮询不会重复请求，离开后重新选择同一英雄仍会重新获取。

## 展示与准确性

- 推荐海克斯按英雄专属胜率排序，展示品质、样本、来源评级、出现轮次和可展开的强化效果。
- 高胜率组合使用接口提供的共同选取统计，不计算单个海克斯胜率的乘积。仅覆盖数据源发布的组合，不能当作所有组合的完整榜单。
- 默认高分段、至少 100 个样本；可切换全段位、轮次、品质与样本门槛。组合页为全轮次、全品质，轮次和品质筛选会禁用；样本门槛仍生效。
- 展示来源、版本、数据发布日期、本次获取时间及英雄总体样本和胜率。实时获取是每次查询最新已发布统计，不表示统计源逐秒更新。
- 换英雄立即清空旧卡片；旧请求即使晚返回也不能覆盖新英雄。请求失败展示错误和重试入口，不将缺失数据显示为 0%。
- 国内端点失败时重新查询同源国际端点的最新版本，不读取本地快照。外部 HTTPS 请求独立校验证书。

## 选人侧窗与主面板

- 默认开启选人自动侧窗，识别 LeagueClientUx 的可见主窗口，优先贴右侧，右边不足贴左侧，两边不足时在当前屏幕工作区内浮动。
- 自动展示时不抢焦点，跟随客户端位置；客户端最小化、切到其他程序或离开选人时隐藏。关闭侧窗后当前英雄不再自动弹出，换英雄会恢复。
- 主面板可主动打开侧窗，也可关闭自动吸附；主面板折叠区中可查看同一套推荐。
- 主面板优先展示英雄、海克斯和队友；参数默认折叠，日志区缩短。队友使用两行展示姓名/评级与英雄/战绩，修复战绩提示中的缺失负场数及参数修改后不刷新的评级。
- 自动接受开关保持用户配置；功能说明显示实际延迟范围。

## 验证结果与边界

- Windows 自带 C# 5 编译器编译成功，21 项自检通过。包括 LCU 选人联动、同英雄下一局重查、快速换英雄的响应顺序、失败清空和多屏坐标。
- 使用正式二进制的 HexData 代码联网获取：16.21 / 2026-10-30；镕铁少女高分段 127 个强化、10 个组合，英雄样本 315,083；九尾妖狐全段位 138 个强化、10 个组合，英雄样本 1,744,554。统计数量会随源站更新变化。
- 真实 WebView2 通过 13 项界面检查：推荐与组合、筛选、换英雄清空、错误与重试、无脚本错误、358px 侧窗宽度、主面板四位队友首屏可见等。
- 本轮未在真实英雄联盟选人界面进行吸附操作，也未进入真实对局；自动接受、经济差等沿用 1.2.0，已通过本地回归，不宣称本轮真实对局验证完成。上机项目见 VERIFY-CHECKLIST.md。

## 源码与复验

- src/HexData.cs：在线请求、规范化、请求代次隔离。
- src/HexWindow.cs：选人侧窗、原生窗口识别、吸附与前台跟随。
- wwwroot/hex-view.js、hex.css、hex.html：主面板与侧窗共享渲染。
- test.bat：21 项自检；node tools/check-ui.js：页面脚本和引用检查。
- Windows PowerShell 运行 tools/verify-hex-live.ps1：直接测试 out/HaiDouAssistant.exe 中的在线取数代码，需网络。
- tools/UiSmoke.cs：WebView2 检查工具，使用工作区 _research/hex-live 中的抓取响应，仅用于开发验证。抓取响应、测试程序及浏览器缓存均不打包到交付物。

## 升级

先从托盘退出旧版本，再解压覆盖程序文件；保留原有 hxdou-data 配置。面板日志右侧应显示 v1.3.0。默认启用海克斯侧窗，但不会替用户开启自动接受或聊天播报。
